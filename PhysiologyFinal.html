⚡Membrane Transport — Rapid Chains

  • DΦ↑ Na⁺/K⁺-ATPase activity → ↑ Na⁺ extrusion + ↑ K⁺ uptake → stronger transmembrane gradients.
  • DPATP depletion → ↓ Na⁺/K⁺ pump → intracellular Na⁺ ↑ → water enters cell → cell swelling.
  • DΦ↑ extracellular K⁺ → K⁺ gradient ↓ → resting Vm becomes less negative.
  • DPSevere sustained hyperkalemia → persistent depolarization → fast Na⁺ channel inactivation → conduction slows.
  • DP↓ extracellular Ca²⁺ → membrane threshold effectively falls → excitability ↑ → tetany.
  • DΦ↑ membrane permeability to K⁺ → Vm moves toward EK → hyperpolarization.
  • DΦ↑ membrane permeability to Na⁺ → Vm moves toward ENa → depolarization.

  • DΦPersistent K⁺ conductance → relative refractory period.

  • DΦVariable ↑ → sensor firing/output ↑ → corrective effector activated → variable driven ↓ = negative feedback.
  • DPNegative feedback lost → same disturbance produces larger deviation.
  • DΦPositive feedback → initiating change amplifies itself until an external endpoint terminates it.

🩸Hemostasis — Directional Chain

  • DΦVessel injury → vasoconstriction → platelet adhesion → platelet activation → aggregation → thrombin → fibrin.
  • DΦThrombin ↑ → additional clotting-factor activation ↑ = positive feedback.
  • DΦPlasminogen → plasmin → fibrin degradation.
  • PPlatelet count/function ↓ → mucocutaneous bleeding ↑.
  • PCoagulation factor deficiency → deep bleeding/hemarthrosis ↑.
  • PFibrinolysis excessive → clot stability ↓ → bleeding ↑.

🧮Master Equations

Cardiac output
CO = HR × SV
HR = beats/min; SV = mL/beat · e.g. 70 × 70 = 4.9 L/min
Stroke volume
SV = EDV − ESV
EDV, ESV in mL · e.g. 120 − 50 = 70 mL
Ejection fraction
EF = SV/EDV × 100
Fraction ejected · e.g. 70/120 = 58%
MAP
MAP ≈ DBP + ⅓(SBP−DBP)
Normal HR approximation · e.g. 80 + ⅓(40) = 93 mmHg
Systemic flow
Q = ΔP/R
Pressure gradient / resistance · ↑R → ↓Q if ΔP fixed
Systemic pressure
MAP − RAP ≈ CO × TPR
RAP usually small · MAP ≈ CO × TPR
Venous return
VR = (Pms − RAP)/RVR
Pms = mean systemic filling pressure · ↑RAP → ↓VR
Fick principle
CO = V̇O₂/(CaO₂−CvO₂)
O₂ consumption / A-V O₂ difference · e.g. 250/50 = 5 L/min
Poiseuille relation
R ∝ 1/r⁴
r = vessel radius · ½ radius → resistance ×16

🫀Cardiac Cycle — One-Line Chains

  • DΦAtrial pressure > ventricular pressure → AV valve opens → ventricular filling ↑.
  • DΦVentricular pressure > atrial pressure → AV valve closes → S1.
  • DΦVentricular pressure > aortic pressure → aortic valve opens → ejection.
  • DΦAortic pressure > ventricular pressure → aortic valve closes → S2.
  • DΦ↑ EDV → ↑ fiber stretch → ↑ contractile force → ↑ SV = Frank–Starling.
  • DP↑ afterload → ESV ↑ → SV ↓ → EF ↓ acutely.
  • DΦ↑ contractility → ESV ↓ → SV ↑ → EF ↑.
  • DP↓ ventricular compliance → filling pressure ↑ at a given volume.

🩺Blood Pressure Regulation

  • DΦMAP ↑ → carotid/aortic stretch ↑ → baroreceptor firing ↑ → medullary sympathetic output ↓ + vagal output ↑ → HR/contractility/TPR ↓ → MAP falls.
  • DΦMAP ↓ → baroreceptor firing ↓ → sympathetic output ↑ → HR/contractility/TPR/venous tone ↑ → MAP rises.
  • CΦProlonged volume depletion → renin ↑ → Ang II ↑ → aldosterone ↑ → Na⁺ retention ↑ → ECF volume ↑.
  • DPRenal Na⁺ excretion impaired → ECF volume ↑ → arterial pressure chronically ↑.
  • Guyton specifically identifies baroreceptors as a rapid pressure-control mechanism and kidneys as dominant long-term controllers.

🎯Creatinine Relationship

  • DPGFR ↓ 50% → creatinine clearance ↓ → plasma creatinine rises toward ~2× baseline at steady state.

  • CΦPlasma creatinine rises until filtered/excreted creatinine again equals production.
  • Guyton explicitly describes this inverse steady-state GFR–creatinine relation.

🏁Final 30-Second PLE Recall

  • CO = HR × SV.
  • SV = EDV − ESV.
  • EF = SV/EDV.
  • MAP ≈ DBP + ⅓ pulse pressure.
  • Flow = ΔP/R.
  • Resistance ∝ 1/r⁴.
  • VR = (Pms−RAP)/RVR.
  • ↑ RAP → ↓ VR.
  • ↑ preload → ↑ SV.
  • ↑ afterload → ↑ ESV, ↓ SV.
  • ↑ contractility → ↓ ESV, ↑ EF.
  • β₁ = Gs; M₂ = Gi; α₁ = Gq; β₂ = Gs.
  • Ventricular phase 0 = Na⁺ in; phase 2 = Ca²⁺ in; phase 3 = K⁺ out.
  • SA-node phase 0 = Ca²⁺ in; phase 4 slope determines HR.
  • Right O₂-Hb shift = ↑H⁺, ↑CO₂, ↑temperature, ↑2,3-BPG.
  • Hypoxic lung vasoconstricts.
  • PaO₂ does not equal O₂ content.
  • GFR ≈125 mL/min; RPF ≈625–650 mL/min; FF≈20%.
  • 50% GFR loss → creatinine ~2× at steady state.
  • ADH = water; aldosterone = Na⁺ retention/K⁺ secretion.
  • Respiratory disorder starts with CO₂; metabolic disorder starts with HCO₃⁻.
  • PTH ↑ Ca²⁺, ↓ phosphate.
  • High sustained estradiol → LH surge.
  • Prolactin makes milk; oxytocin ejects it.
  • UMN lesion → hyperreflexia; LMN lesion → hyporeflexia.
  • Cerebellum = coordination/error correction; basal ganglia = movement selection.
  • PaCO₂ ↑ → cerebral blood flow ↑.
  • Light → photoreceptor hyperpolarization.
  • Cochlear hair cell → K⁺ influx causes depolarization.
  • Best PLE sequence: identify primary change → predict direct effect → identify sensor/integrator → predict compensation → decide whether compensation restores or worsens the clinical state.
